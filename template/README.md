# spur-hello

What it is, in a line.

A [Switch](https://switch.ax) spur, built on [spur-kit](https://github.com/zachsents/spur-kit).

## Install

Ask Switch's agent to install `github:OWNER/spur-hello`, or add it in the desktop's Spurs view
(⌘K, Spurs).

## Develop

```sh
bun install
bun run check
bun start   # serves MCP on stdio
```
